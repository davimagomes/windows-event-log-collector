# About

This project is developed to run on `Windows OS`, specifically targeted to run as a standalone executable on each computer across the corporate network.

---

# System Requirements

This project requires a Windows environment.

* **C++ Standard:** C++20
* **Compiler:** GCC/G++ 11 or higher
* **CMake:** Minimum version 3.10

---

# Installing Dependencies
 
This project has no external dependencies.
